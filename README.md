# MagicalNotesApp

Волшебное приложение для заметок / Magical notes app.

---

## О проекте

**MagicalNotesApp** — это личный веб-сервис для заметок, текстов, мыслей и идей.
В отличие от обычных блокнотов, здесь заметки живут на **свободной доске**: их можно
перетаскивать, изменять размер, прикреплять к ним фотографии и гифки, а также
соединять заметки **нитями связей** — чтобы видеть, как одна идея перетекает в другую.

Сервис сделан для личного использования — без регистрации и авторизации, с
простым REST API и хранением данных в БД.

---

## Ключевые возможности

### Иерархия папок
- Создание папок любого уровня вложенности.
- Переименование и удаление вместе со всем содержимым.
- Быстрый поиск по названиям.
- Раскрывающееся дерево в сайдбаре с анимацией.

### Заметки
- Свободное расположение на бесконечной доске.
- Перетаскивание мышью за заголовок.
- Редактирование по двойному клику.
- Настраиваемый цвет фона заметки.
- Заголовок + многострочный текст.

### Вложения (фото, скриншоты, гифки)
- Загрузка через модалку заметки.
- **Свободное перетаскивание** — в том числе за пределы заметки.
- **Изменение размера** — за синий кружок в правом нижнем углу.
- Отображение без обрезки (`object-fit: contain`).
- Удаление одним кликом по крестику.
- Автоматическая **пунктирная нить** «заметка ↔ вложение», когда картинка
  вынесена за границы заметки.

### Нити связей между заметками
- Потяни за кружок в правом верхнем углу заметки — и соедини с другой.
- Клик по нити — удаление связи.
- Подсветка при наведении.
- Плавные кривые Безье.

### Интерфейс
- Палитра: **белый + синий** с мягкими акцентами.
- Адаптивная вёрстка — работает на десктопе и мобильных.
- Плавные анимации появления, hover-эффекты.
- Мобильное меню-«гамбургер» в правом нижнем углу.
- Пан доски — протягивание пустого места.

## Технологический стек

| Слой | Технология |
|---|---|
| Backend | PHP ≥ 7.4, Yii2 (framework + REST) |
| Frontend | HTML5, CSS3, нативный JavaScript (ES6+) |
| UI-фреймворк | Bootstrap 5.3 + Bootstrap Icons |
| База данных | MariaDB / MySQL / PostrgeSQL / SQLite |
| Composer | для управления зависимостями |

Специально **без сборщиков** (webpack, vite) — весь фронтенд на чистом JS и CSS,
чтобы можно было легко читать и править.

## Установка и запуск

### Требования
- PHP **7.4+** (лучше 8.0+)
- Composer 2.x
- MariaDB 10.3+ или MySQL 5.7+
- Веб-сервер: Apache (XAMPP) или встроенный `php -S`(php -S localhost:8080 -t frontend/web)
